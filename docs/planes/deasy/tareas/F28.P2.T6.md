Una **sesión** sí es un proceso: se repite, tiene responsables y produce documentos (convocatoria, acta, resoluciones). Con el órgano como unidad, eso lo hace el motor que ya existe, sin modelar nada. El **quórum** y la **votación** no son procesos ni tareas: son hechos que el acta deja escritos. Sólo pedirían modelo propio si el sistema tuviera que calcularlos o impedir una decisión sin quórum.

Y enlaza con F27: la resolución que sale de una sesión es el documento de un acto (`F27.P4.T7`).
